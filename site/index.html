HOW IT WORKS

One useful change at a time.

For creators, an app is a starting point. Ask for what you need, try it on your phone, and decide what stays.

  1. 01

    Describe your idea

    Start with an idea for an app. As you use it, ask for tweaks and new features from its Coding page.

  2. 02

    Try the build

    An AI coding agent makes the changes. Mytheseus builds an Android app for you to install and try.

  3. 03

    Choose what stays

    Use it on your phone. Keep the change if it works for you, or ask for another revision.

ABOUT THE PROJECT

Why Mytheseus?

Like the ship of Theseus, an app can change a piece at a time while staying yours. Mytheseus is an experiment in software that adapts to real needs through small, reviewable steps.

Mytheseus is an early, self-hosted project for Android. Creation access is currently limited to invited participants. Anyone can try the shared apps in the public example collection above.
