HOW IT WORKS

One useful change at a time.

For creators, an app is a starting point. Ask for what you need, try it on your own device, and decide what stays.

  1. 01

    Describe your idea

    Start a web app, for iPhone, Android and computers, or a native Android app. As you use it, ask for tweaks and new features from its Coding page.

  2. 02

    Try the new version

    An AI coding agent makes the change and Mytheseus builds it. A web app switches to the new version on your device; an Android app installs it as an update.

  3. 03

    Choose what stays

    Keep the change if it works for you, ask for another revision, or put the previous version back. People you share the app with get only the versions you keep.

WHAT IT DOES

Everything around the app.

Mytheseus builds, delivers and updates your app, and looks after the parts around it: who can use it, how they hear about changes, and what it can connect to.

  • Web apps on phones and computers

    A web app works on iPhone, Android and computers. It opens from a link, lives at its own address, and can be added to the home screen. There is no app store step.

  • Native Android apps

    An Android app is a real installed app, delivered as an APK rather than through an app store. It checks for its own updates and lets you know when one is ready.

  • Accounts and teams

    Sign in with a code sent to your email; Google sign-in is being tested. The apps you make are yours. Give one to a team, and its members can change it with you.

  • Public apps and copies

    Make an app public to list it in the gallery for anyone to use. Signed-in people can start their own copy, even as the other kind of app, unless you turn copies off.

  • App icon studio

    Upload a picture, or describe an idea and choose from up to four AI-drawn icons. A new icon is tried and kept like any other change.

  • Notifications

    Hear when a change is ready to try or a question needs you. People using a shared app hear about new versions. On iPhone, add the web app to the Home Screen first.

  • Google Calendar, being tested

    Web apps will be able to read a person’s Google Calendar, read-only, once they connect it for that app, and disconnect it from the app’s settings at any time. Native Android apps can’t use it.

  • Activity, kept private

    See how shared apps are used, counted on the Mytheseus server with no third-party scripts. In shared web apps, people are told first, can stop launch reports, and nothing they type is collected.

  • Foundations that improve

    The parts every app shares, like Coding and Updates, keep getting better. Android apps take each improvement as an update you try and keep; web apps get it with server updates.

Some of these depend on how a Mytheseus server is set up: emailed sign-in codes and AI icon ideas need its operator to switch them on, and so will Google sign-in and Calendar once their testing is done.

ABOUT THE PROJECT

Why Mytheseus?

Like the ship of Theseus, an app can change a piece at a time while staying yours. Mytheseus is an experiment in software that adapts to real needs through small, reviewable steps.

Mytheseus is an early, self-hosted project. It makes web apps that work on iPhone, Android and computers, and native Android apps. Creation access is currently limited to invited participants. Anyone can try the shared apps in the public example collection above.

Start with one small idea.

Creating apps is by invitation while Mytheseus is early. If you have been invited, sign in to make your first app. On Android, anyone can try the example apps.
