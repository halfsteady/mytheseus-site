HOW IT WORKS

One useful change at a time.

Mytheseus gives a person a clear way to ask for a change and decide what happens to their app.

  1. 01

    Make a request

    Describe a small tweak, a new feature, or a problem from the app’s Coding page.

  2. 02

    Try the build

    A coding agent updates the app. Mytheseus builds a signed Android APK for you to install and try.

  3. 03

    Choose what stays

    Keep the change, request another revision, or cancel. Restoring after an app data change may need operator review.

MADE FOR PEOPLE

Personal to create.
Easy to share.

The creator edition includes Coding. When a version is ready to share, an operator can build a separate user edition from kept changes. People using that edition receive updates without the coding controls.

ABOUT THE PROJECT

Why Mytheseus?

Like the ship of Theseus, an app can change a piece at a time while staying yours. Mytheseus is an experiment in software that adapts to real needs through small, reviewable steps.

It runs on a self-hosted server with an Android Hub for the operator to manage apps and releases. Apps are installed as APKs. This is an early project for trusted participants, rather than an open app marketplace.
