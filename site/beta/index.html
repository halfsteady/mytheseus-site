HOW IT WORKS

Ask. Try. Keep.

An app is a starting point. As you use it, ask for what it’s missing. Nothing changes for good until you say so.

  1. 01

    Ask in plain words

    Open your app’s Coding page and answer “What would you like to change?”. Pick Small tweak, New feature or Something’s wrong. In a web app, type @ to point at a connection.

  2. 02

    Try it on your device

    An AI coding agent makes the change and Mytheseus builds it. When it’s Ready to try, press Try it: a web app switches this device to it; an Android app installs it as an update.

  3. 03

    Keep what works

    Keep it, Change something, or Put it back. In a web app, a new version that doesn’t start is never left on screen.

TWO KINDS OF APP

On every screen you use.

Choose when you start. Want the other kind later? Make a copy as the other kind; it’s rebuilt as its first change.

Web app

For iPhone, Android and computers. Its starter version is ready to open within seconds; your first request shapes it.

  • Opens from a link at its own address
  • Add it to the Home Screen, or install it from the browser
  • New versions switch over on the device, no store step
  • Can connect to outside tools; Google Calendar (read-only) is being tested

Android app

A real installed app, delivered as an APK rather than through an app store.

  • Home-screen widgets, like Draw a widget below
  • Checks for its own updates and tells you when one is ready
  • Try a new version, then keep it or put the old one back
  • Android will ask you to allow app installs

MADE FOR PEOPLE

Personal to make.
Easy to share.

The people you share with get the app and the versions you keep, without the coding controls. Pick how far it goes.

  1. Just you, or your team

    Apps are private to start. Give one to a team, and its members can change it with you.

  2. A share link

    Send a link or QR code to the app’s user edition. Web app links last 7 days and up to 10 devices by default; Android install links work once, for ten minutes.

  3. A Hub

    Gather web and Android apps behind one link, at an address of their own, like name.hub.mytheseus.app. Android apps in a Hub open in the Hub app. Turn a link off and the access it gave ends.

  4. Open or public

    Make a web app open to anyone with its address, or make any app public in the gallery for anyone to find and use.

  5. Copies

    Signed-in people can make their own copy of a public app to change, even as the other kind, unless you turn copies off.

WHAT’S INSIDE

Everything around the app.

Mytheseus builds, delivers and updates your app, and looks after the parts around it.

  • Safe to try

    Every change is a trial until you keep it, and you can put the previous version back. In a web app, a version that doesn’t start is never left on screen.

  • Connections

    A web app can show live data from an outside tool, like metrics from Grafana. The server holds the credentials, and each tool is set to off, read or write.

  • Google Calendar, being tested

    Web apps will be able to read a person’s calendar, read-only, once they connect it for that app, and disconnect it from App settings at any time. Native Android apps can’t use it.

  • App icon studio

    Upload a picture, or describe an idea and choose from up to four AI-drawn icons. A new icon is tried and kept like any change.

  • Notifications

    Hear when a change is ready to try or a question needs you. People using a shared app hear about new versions. On iPhone, add the web app to the Home Screen first.

  • Accounts and teams

    Sign in with a code sent to your email; Google sign-in is being tested. The apps you make are yours; give an app or Hub to a team to work on it together.

  • Activity, kept private

    See how shared apps are used, counted on the Mytheseus server with no third-party scripts. Shared web apps tell people before sending launch reports, which they can stop, and explain what the server records anyway. Activity never includes what people type.

  • Foundations that improve

    The parts every app shares, like Coding and Updates, keep getting better. When Coding offers a foundation upgrade, you try and keep it like any other change.

Some of these depend on how a Mytheseus server is set up: its operator switches on emailed sign-in codes, AI icon ideas and connections, and will do the same for Google sign-in and Calendar once their testing is done.

ABOUT THE PROJECT

Why Mytheseus?

Like the ship of Theseus, an app can change a piece at a time while staying yours. Mytheseus is an experiment in software that adapts to real needs through small, reviewable steps.

It is an early, self-hosted project. Making apps is by invitation for now. Anyone can try the web demos, and Android users the example collection.
